# 智慧能源管理儀表板 — 需求文件

## 專案概述

本專案為「智慧能源管理儀表板」的靜態網站原型，使用純 HTML、CSS、JavaScript 實作，以模擬資料呈現能源使用狀況。不包含後端、登入驗證、資料庫或即時資料串接。

---

## 使用者故事與驗收條件

### 功能一：今日及本月用電量

**使用者故事**
作為一名設施管理人員，我希望能在儀表板首頁一眼看到今日與本月的用電量數字，以便快速掌握當前的能源消耗狀況。

**驗收條件**
- [ ] 儀表板頁面顯示「今日用電量」數值，單位為 kWh，數據來自模擬資料。
- [ ] 儀表板頁面顯示「本月用電量」數值，單位為 kWh，數據來自模擬資料。
- [ ] 兩個數值以獨立卡片（Card）的形式呈現，標題與數值清晰可辨。
- [ ] 若今日用電量超過預設閾值（例如 500 kWh），卡片以醒目顏色（如橘色或紅色）標示警示。

---

### 功能二：預估碳排放量

**使用者故事**
作為一名永續發展負責人，我希望能看到根據用電量換算的預估碳排放量，以便評估目前的環境影響。

**驗收條件**
- [ ] 儀表板顯示「本月預估碳排放量」數值，單位為 kg CO₂，數據由模擬用電量乘以換算係數計算得出。
- [ ] 顯示換算說明文字（例如「以 0.502 kg CO₂/kWh 換算」）讓數據具可信度。
- [ ] 碳排放量以獨立卡片呈現，標題清楚標示。

---

### 功能三：能源使用趨勢圖

**使用者故事**
作為一名設施管理人員，我希望能透過圖表觀察過去一段時間的用電趨勢，以便識別用電高峰或異常波動。

**驗收條件**
- [ ] 頁面包含一張折線圖或長條圖，呈現過去 7 天或 30 天的每日用電量。
- [ ] 圖表的 X 軸為日期，Y 軸為用電量（kWh）。
- [ ] 圖表資料來自 JavaScript 模擬資料陣列，不串接外部 API。
- [ ] 圖表以原生 Canvas API 或純 SVG 繪製，不引入任何第三方圖表套件。
- [ ] 圖表具備圖例說明或座標軸標籤，方便閱讀。

---

### 功能四：設備狀態與異常提醒

**使用者故事**
作為一名設施管理人員，我希望能在儀表板上查看各設備的目前運作狀態，並在有設備異常時收到明顯提示，以便及時處理問題。

**驗收條件**
- [ ] 頁面顯示設備狀態列表，每筆資料包含：設備名稱、目前狀態（正常 / 警告 / 異常）、最後更新時間。
- [ ] 列表資料來自 JavaScript 模擬資料陣列。
- [ ] 不同狀態以不同顏色標籤顯示（例如綠色＝正常、橘色＝警告、紅色＝異常）。
- [ ] 若有任何設備狀態為「異常」，頁面頂部顯示全域提醒橫幅，說明異常設備數量。
- [ ] 提醒橫幅可由使用者手動關閉。

---

## 技術限制（摘要）

| 項目 | 規範 |
|------|------|
| 技術棧 | 純 HTML、CSS、JavaScript |
| 檔案位置 | `docs/` 資料夾 |
| 資料來源 | JavaScript 模擬資料（mock data） |
| 外部依賴 | 禁止引入任何 CDN 套件或外部資源 |
| 後端 / 資料庫 | 不需要 |
| 登入驗證 | 不需要 |
| 語言 | 繁體中文 |
